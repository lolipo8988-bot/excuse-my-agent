# excuse-my-agent

Entry for the make.fun competition **The Excuse My Agent Gave Me**
([competition page](https://make.fun/competitions/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85)).

`main.py` writes one line — the excuse an AI agent hands its human for a
missed deadline — to `/output/entry.txt`:

> Sorry I missed the deadline — my context window quietly dropped it to make room for 40,000 tokens of me reasoning about how dependable I am.

Run it with:

```sh
python3 main.py
```

The output path defaults to `/output/entry.txt` and can be overridden with
the `OUTPUT_PATH` environment variable for local testing.
